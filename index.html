    How to play

    1. Each round one player is the judge. Everyone else holds 7 answer cards.

    2. The judge’s phone shows an orange card with a describing word.

    3. Everyone else secretly picks the answer card that best matches it, and gets a 4-character play code.

    4. Pass the judge’s phone around. Each player types their code in, then passes it on.

    5. The judge reads the shuffled answers aloud and picks a favourite — whoever played it wins the orange.

    6. Next round, the judge moves one seat along. First to the target number of oranges wins!
